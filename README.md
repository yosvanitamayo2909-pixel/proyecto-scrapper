# 🕷️ Web Scraping & Data Extraction Specialist - Python Portfolio

Script de automatización y extracción de datos desarrollado en Python para la recolección estructurada de información web.

## 🚀 Tecnologías Utilizadas
* **Python** (Lenguaje principal)
* **Requests & BeautifulSoup** (Para parsing y peticiones HTTP eficientes)
* **Selenium** (Para automatización de sitios dinámicos / JavaScript - *según aplique*)
* **Manejo de Bases de Datos & Archivos** (CSV / JSON / SQL)

## 💡 ¿Qué resuelve este script?
Este repositorio demuestra mi capacidad para:
1. Conectarme a sitios web de forma segura y extraer datos específicos.
2. Limpiar y estructurar la información en formatos listos para negocio (CSV, bases de datos).
3. Escribir código limpio, modular y documentado.
